## 🎯 About The Project

Sorting is a foundational concept in computer science. This project implements six core sorting algorithms from scratch, ranging from simple O(n²) approaches to highly efficient O(n log n) divide-and-conquer strategies. It is designed to be easily readable for educational purposes and algorithmic practice.

---

## 🧠 Algorithms Included

1. **Bubble Sort:** A simple comparison-based algorithm that repeatedly steps through the list, swaps adjacent elements if they are in the wrong order, and "bubbles" the largest elements to the end.
2. **Selection Sort:** Divides the list into a sorted and unsorted region, repeatedly finding the minimum element from the unsorted region and swapping it into the sorted one.
3. **Insertion Sort:** Builds the sorted array one element at a time by picking the next item and inserting it into its correct relative position.
4. **Merge Sort:** A divide-and-conquer algorithm that recursively splits the array into halves, sorts them, and merges the sorted halves back together.
5. **Quick Sort:** An efficient, in-place divide-and-conquer algorithm that partitions the array around a "pivot" element, sorting elements smaller and larger than the pivot recursively.
6. **Heap Sort:** A comparison-based sort that utilizes a binary heap data structure to continuously extract the maximum (or minimum) element and build the sorted array.
